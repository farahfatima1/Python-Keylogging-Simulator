**Python Key Logging Simulator**



A Python-based keylogging simulator developed for controlled cybersecurity education and security awareness.



 **Features**

\- Tkinter graphical interface

\- Keyboard event monitoring within the test input field

\- Timestamped keystroke logging

\- Keystroke statistics and frequency analysis

\- Automated security report generation

```bash

```

```bash

python analyzer.py

```



**Ethical Use**



This project is intended only for authorized, controlled laboratory testing. It captures input only within its application text field. Never enter real passwords or sensitive information.
